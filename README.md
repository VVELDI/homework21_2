# 🛍️ Интернет-магазин "Питание для всех"

Проект интернет-магазина по продаже специализированного питания.

## ✨ Особенности

- Каталог товаров с фильтрацией
- Корзина покупок
- Личный кабинет пользователя
- Административная панель
- Адаптивный дизайн

## 🚀 Быстрый старт

### Установка зависимостей

```bash
pip install -r requirements.txt
```
### Запуск приложения
```bash
python app.py
```

### 📂 Структура проекта

project/
````
├── css/# CSS стили
│   └── bootstrap.min.css
├── js/                   # JavaScript файлы 
├── sidebar.html          # Боковое меню
├── index.html            # Главная страница
├── category.html         # Страница категорий
├── catalog.html          # Каталог товаров
├── contacts.html         # Контакты
├── app.py                # Основное приложение
├── pyproject.toml        # Конфигурация и зависимости Poetry
├── README.md             # Документация
└── .gitignore            # Игнорируемые файлы

````
